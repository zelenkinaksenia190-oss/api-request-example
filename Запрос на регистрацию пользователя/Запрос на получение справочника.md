## Запрос на получение справочника стран

__Метод:__ GET

__URL:__ api/v1/countries

__Пример запроса на сервер:__ https://{домен}/api/v1/countries

Authorization: Bearer <token>

_Тела запроса здесь не будет!_

__Response Body (code and status):__

_200 ОК_

```py 
{
    data: [
        {
            "code": "RU"
            "country": "Россия"
        },
        {
            "code": "BY"
            "country": "Белорусь"
        }
    ]
}

```


__Ошибки:__

1) 400
2) 401 
3) 403
4) 500
